Overview

PentaGraph is a digital recreation of the 5-band graphic EQ circuit found in guitar amplifiers and recreated in standalone pedals with op-amp gyrator circuits. It reproduces the circuit's topology, band interaction and saturation behaviour instead of approximating the frequencies with a generic parametric EQ.

Its behaviour includes band independence, the V-curve scoop, gain-dependent Q narrowing and op-amp saturation when pushed hard.

PentaGraph operates in two modes, selectable via the Analog Modeling toggle in the settings (cog) menu:

  • Nominal mode (the default) uses the pedal's published frequency labels (80 / 240 / 750 / 2.2k / 6.6k) and clean textbook filtering with no saturation. Each band's Q is adjustable (range 0.3-6.0, default 0.667), from broad and musical to narrow and notch-like. Use it for general EQ work.
  • Analog mode uses studio-calibrated centre frequencies, calibrated per-band Q values, nonlinear gain mapping, and dual-stage ADAA saturation (wrapped in 2× IIR oversampling) to reproduce the measured response of the hardware. The user Q controls are bypassed in this mode in favour of the measured values.

Analog Modeling is a fully automatable parameter and is saved and restored with presets, so factory and user presets can each specify which mode to use.

Interface

The workbench-style faceplate presents five band sliders, a real-time frequency-response curve showing the composite EQ shape with a live spectrum analyser drawn behind it, and IO ring meters that animate with the audio thread.

Each band exposes a compact Q slider beneath its gain fader; you can also adjust Q by mouse-wheeling directly over the band's point on the curve display, or via host automation. The preset bar groups settings, including the Analog Modeling toggle, into a sectioned popup, and band points on the curve ease over 120 ms on hover and when active.

Features

  • The five bands are summed in parallel. Each band filters the dry input independently and the contributions are added together, as in the analog circuit's op-amp summing stage. This keeps the bands independent, which cascading five peaking biquads in series does not.
  • Two modes switch from the settings menu. Nominal is clean, textbook EQ with published frequencies and adjustable per-band Q. Analog uses hardware-calibrated frequencies, calibrated per-band Q, nonlinear gain mapping and analog saturation.
  • In Nominal mode each band has its own Q control (0.3-6.0, default 0.667), set with the slider under each fader, by mouse-wheel over the band's point on the curve, or via host automation.
  • All centre frequencies, Q values and gain mappings were derived from studio measurements of a real 5-band gyrator EQ pedal (48 kHz / 24-bit WAV via MOTU interface, spectral division with 1/6-octave smoothing). The measurements showed that Band 1 is a low shelf and Band 5 is a high shelf, with Bands 2-4 as wide peaking filters.
  • In Analog mode the effective Q narrows at extreme boost or cut settings, as in the analog circuit. At ±12 dB the effective Q is ~1.36× the base Q.
  • Analog mode uses dual-stage ADAA saturation with 2× oversampling. Per-band saturation models per-gyrator op-amp headroom, while post-summing saturation models the summing amplifier. Both use first-order Antiderivative Anti-Aliasing with tanh soft clipping, wrapped in 2× IIR oversampling (~43 dB image rejection, ~41 dB reduction in naive-tanh aliasing) with zero reported latency. Per-band drive is envelope-modulated (attack ~1 ms, release ~50 ms) and bypassed entirely at low gain settings.
  • Input and output trims run from −40 to +6 dB with a unity detent at 0 dB, so you can place PentaGraph like an FX-loop EQ. Raising the input trim pushes the saturation stages for more analog character.
  • The 15 factory presets include Classic V, Djent Focus, Jazz Roll-Off and Fuzz Friend. User presets can be saved, renamed and deleted.
  • The audio thread makes no heap allocations, parameter smoothing (15-20 ms) prevents zipper noise, and the plugin is stable across 44.1-192 kHz sample rates, with no denormals or NaN propagation.
  • PentaGraph adds no latency to your signal chain, so it can be used for tracking, mixing and live work.

Installation

macOS

The macOS release is a signed and notarised .pkg installer.

  1. Download PentaGraph-<version>.pkg from the release page.
  2. Double-click the .pkg file to launch the installer.
  3. Follow the on-screen prompts. You can choose which components to install:
    • VST3 plug-in → installed to /Library/Audio/Plug-Ins/VST3/
    • AU plug-in → installed to /Library/Audio/Plug-Ins/Components/
    • Factory Presets → installed to /Library/Application Support/Nullform Audio/PentaGraph/Presets/Factory/
  4. Open your DAW and scan for new plug-ins. PentaGraph will appear under Nullform Audio.

Windows

The Windows release is an Inno Setup .exe installer.

  1. Download PentaGraph-<version>-Windows.exe from the release page.
  2. Run the installer. If Windows SmartScreen appears, click More info → Run anyway.
  3. Choose the installation type:
    • Full installs the VST3 plug-in and factory presets
    • VST3 only installs the plug-in without presets
    • Custom lets you choose components individually
  4. Open your DAW and scan for new plug-ins.
